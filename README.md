# 人联启动器

Paradox 全家桶的第三方启动器，一份程序管十款游戏：十字军之王 II/III、群星、钢铁雄心 IV、维多利亚 3、欧陆风云 IV/V、帝皇：罗马、城市：天际线 1/2。比官方启动器轻，**重点是排序**；除此之外，还有四个真正省事的地方：拖进窗口就能装的 Mod、一键排查播放集冲突、五种界面语言，以及内置的五游戏离线百科。

**开源地址（源码全部公开，可自行审阅 / 编译）**

- **Gitee（主仓库，更新检查也走这里）**：https://gitee.com/xiaoyi2233/renlian-launcher
- **GitHub（镜像仓库）**：https://github.com/xiaoyi201610/renlian-launcher

**下载**：到 Gitee 仓库的 [Releases](https://gitee.com/xiaoyi2233/renlian-launcher/releases) 页取最新版压缩包，解压双击 `人联启动器.exe` 即可，无需安装 Python。

## 四个亮点

### ① 压缩包拖进窗口就装好（不用 7-Zip）

把 `.zip` / `.7z` / `.rar` 从资源管理器拖到启动器窗口**任意位置**，松手即开始：
自动解压 → 找到包里的 `descriptor.mod` → 装进本地 `mod` 目录 → 生成 `.mod` 描述文件 → 刷新模组列表。

- 支持一次拖多个包，界面逐条显示「上传 % → 解压中 → 已安装 / 失败原因」
- 不需要安装 7-Zip / WinRAR：`.7z` / `.rar` 用 Windows 自带的 `tar.exe` 解
- 重名不覆盖：目标目录已存在时自动加 `_2` / `_3`
- 包里没有 `descriptor.mod`、压缩包加密或损坏，会直接说明原因，不会装出一个空壳
- 超过 400MB 的包会先拦下，提示手动解压后放进 `mod` 目录，避免界面卡死

### ② 播放集冲突排查

「模组管理」右上角点 **冲突排查**，扫描当前播放集里**所有已启用模组**，输出四类结果：

| 类型 | 说明 |
|---|---|
| 文件覆盖 | 同一个相对路径被多个模组包含。按加载顺序，**越靠下越晚加载、最终生效**；面板直接标出「谁赢了、谁被盖住」 |
| 本地化键重复 | 多个模组在 `.yml` 里定义了同一个 key，属于软冲突，表现为文本随机被某一家覆盖 |
| 依赖缺失 | 模组声明了 `dependencies`，但依赖项没有启用 |
| 整目录替换 | 模组用 `replace_path` 替换原版整个目录，风险最高，单独提示 |

结果按 **高 / 中 / 低** 分级（`common/`、`events/`、`history/` 等高影响路径优先），并带逐模组扫描进度，大播放集也不会看起来像卡死。结果缓存 20 秒，改完顺序再点一次即可刷新。

### ③ 五种界面语言

简体中文 / English / Français / Deutsch / Svenska，在「启动器设置 → 界面语言」切换，**即时生效并记住**。除界面文案外，DLC 分类、日期、数量单位等也跟随切换；DLC 名称在中文界面显示中文，其他语言显示 Steam 原名。

### ④ 内置小百科，快速查找

侧边栏「百科」把最容易忘的资料做成速查表，现已收录**五款游戏、共 18537 条 + 293 棵树**：

- 《十字军之王 3》七类 932 条：军队兵种、文化、传统、宗教、革新、信条、教义
- 《群星》十类 2436 条：国民理念、起源、飞升天赋、传统、法令、政策、遗物、标本、科技、物种特质
- 《钢铁雄心 IV》三类 9170 条 + 67 棵国策树：国家理念、军官团与顾问，国策树可缩放拖动
- 《维多利亚 3》法律 148 条（26 组）+ 利益集团 8 个 + 集团特质 98 条
- 《欧陆风云 IV》七类 5745 条 + 226 棵任务树：思想组、陆军、陆军单位、海军单位、海军、时代、任务树（按槽位分列、按前置分层，可缩放拖动）

全部**离线**读取游戏本体脚本与官方本地化，支持搜索与分类筛选，点条目展开详情（数值、效果、克制关系等），每个条目还能跳转官方 Wiki。游戏更新或装新 DLC 后点「重建索引」即可刷新，不联网、不抓 wiki 正文。

## 重新打包 exe

改完代码后要重新生成绿色版，三步：

```bash
# 1. 打包单文件 exe（约 40 秒）
python -m PyInstaller build.spec --noconfirm --distpath dist --workpath build

# 2. 组装绿色目录 + 压缩包
python make_release.py

# 3. 产物在 release/人联启动器_v<版本>.zip（版本号取 make_release.py 里的 VERSION）
```

`build.spec` 里有两个关键点，改动时别删：

- `pathex=['backend']` 与 `hiddenimports=['server','ck3core']` —— 否则 PyInstaller 静态分析找不到 `backend/` 下的模块，打出来的 exe 一启动就闪退
- `excludes` 里不要加 `distutils` / `setuptools` / `unittest`，会和 PyInstaller 自身 hook 冲突报错

打包后的资源路径处理：`ck3core.RES_DIR` 指向 PyInstaller 临时目录（放 `static/`），
`ck3core.APP_DIR` 指向 exe 所在目录（放配置和 `backups/`）。

## 排序是怎么生效的

CK3 有**两套**并存的数据，只改一处是不够的：

1. `launcher-v2.sqlite` → `playsets_mods.position`：官方启动器界面里看到的顺序
2. `dlc_load.json` → `enabled_mods` 数组：**游戏启动时真正读取的加载顺序**

本启动器每次保存会**同时写这两处**，所以：
- 用我的启动器排完序，再开官方启动器，顺序是对的
- 直接点「开始游戏」跳过官方启动器，进游戏也是对的

> **越靠下优先级越高**：后加载的模组会覆盖先加载的同名文件。
> 所以大型框架类模组放上面，补丁/汉化放下面。

## 数据安全

写盘前会自动备份到 `backups/`，最多保留 30 份：

- `launcher-v2-YYYYMMDD-HHMMSS.sqlite`
- `dlc_load-YYYYMMDD-HHMMSS.json`

**官方启动器开着的时候保存会失败**（数据库被独占锁），启动器会提示你先关掉它。

想手动回滚：把 `backups/` 里对应时间的文件复制回
`C:\Users\<你>\Documents\Paradox Interactive\Crusader Kings III\` 覆盖即可。

## DLC 中文名（出新 DLC 怎么加翻译）

Paradox 在 Steam 商店里没给 DLC 设中文名（`l=schinese` 拉回来还是英文），
游戏本体的中文语言包里也**没有 DLC 名称条目**（DLC 名只在启动器和商店显示，
游戏内不显示，所以官方没做这部分本地化）。因此本程序内置了一份对照表：
`backend/dlc_cn.py`。

**以后 Paradox 出新 DLC，只要在里面加一行：**

```python
"英文名": "中文名",
```

例如：

```python
"the great wave": "大浪潮",
```

就能显示中文。**即使不改，也只会那一个新 DLC 显示英文，其他照常，不影响使用。**

几个说明：

- 键用**英文名**（不是目录名）：目录名各游戏规则不同、还会随版本变，英文名更稳定
- 写之前不用管前缀，`normalize()` 会自动剥掉
  `Expansion - Europa Universalis IV:` / `Music -` / `Country Pack -` /
  `Victoria 3: ... - Immersion Pack` 这类前后缀，只留核心名
- 已有 295 条，覆盖 ck3 / stellaris / hoi4 / vic3 / eu4 / eu5 / ck2 /
  imperator / skylines / skylines2
- CK3 另有一张按目录名索引的老表 `DLC_CN`（在 `ck3core.py` 里），
  优先级更高，中文名以它为准

**改完记得把 `server.py` 里的 `_DLC_CACHE_VER` +1**，否则玩家本机缓存里
还是旧名字，看不到变化。

> **为什么不做内嵌网页**：paradoxwikis 前置了 Fastly 的 JS 人机校验，程序直连只会拿到校验页（已实测，连 `api.php` 也被挡）。抓正文既脆弱又涉及版权；改用游戏本体脚本反而更准、更快、断网可用。
>
> 目前支持《十字军之王 3》《群星》《钢铁雄心 IV》《维多利亚 3》《欧陆风云 IV》，切到其他游戏会提示「暂未收录」。要加新分类，只需在对应模块里写一个 `_collect_xxx()` 并登记到 tab 表。

群星本地化里有一堆引擎标记，解析时全部清洗：`£icon£`（内联图标）、`§Y…§!`（颜色区间）、`$var$`（含 `$tech_x_desc.1$` 这类分段号与 `$@脚本值|0$`）、`['concept_x']`（概念引用）与 `['icon', 文本]`（图标+文本二元组）。数值统一按修饰器键后缀换算：`*_mult` 乘 100 加百分号，其余按绝对值。

- **`inline_script` 隐形词条**：22 条传统的效果根本不写在 `common/traditions`，而是指向 `common/inline_scripts/traditions/*.txt`，必须跟进才能显示（如「染色体增长」「优化神经学」）。

## 1.6 新增：版本切换与文件独立

「游戏本体版本」和「存档 / 模组」本来是两件不同的事，1.6 把它们分开管，侧边栏多了一个「版本切换」页。

### ① 版本配置（多版本，各管各的数据）

每个游戏都能建多套配置，每套拥有独立的**游戏本体目录 / 创意工坊目录 / 用户数据目录**，切一套就是整套存档、模组、设置一起换。

- 新增时自动分配独立数据目录（默认目录的兄弟目录，如 `…\Crusader Kings III - 1.19`），不用自己想名字
- 每条可设名称 / 版本号 / 数据目录，支持「浏览」改路径、「打开」直达资源管理器
- 建到 2 套以上，顶栏出现**版本下拉**，一键切换；下拉按当前游戏独立，不会串到别的游戏
- 要真正隔离必须开启 `-dataPath`（卡片里有一键开关，可开可关）；不开则各版本共用同一个默认目录

### ② 通过 Steam 切换游戏本体版本

直接读写 Steam 清单 `appmanifest_<AppID>.acf` 里的 `UserConfig.BetaKey` —— 与 Steam「属性 → 测试版」改的是**同一个字段**，不存在「启动器专用版本」。

- 自动抓取当前游戏在 Steam 里的**全部分支**，默认公开版本置顶；CK3 / 群星 / 钢铁雄心 4 / 欧陆风云 4-5 / 维多利亚 3 / CK2 / 帝皇罗马 / 城市天际线等通用
- 流程：选分支 → 切换 → 确认 → 启动器自动关闭 Steam → 写入分支 → 重启 Steam → Steam 自动下载
- 切换前自动备份 `appmanifest_<AppID>.acf.bak`，可随时还原
- 相邻版本通常只补差量（几百 MB），跨大版本可能几 GB；下载完成前进游戏版本号不会变

> 切换前游戏必须完全退出。若任务管理器里残留杀不掉的僵尸 `ck3.exe`，只能**重启电脑**清掉，否则 Steam 会显示在下载、进度却不动。

### ③ 启动器自带检查更新

设置页「版本自检」点「检查更新」，直接用内置 Gitee 源比对，有新版就显示版本号 / 日期 / 说明并给出下载按钮，**不需要自己填更新地址**。

## 常见问题

**Q：窗口打不开？**
用 `启动器-调试.bat` 看报错。如果提示 webview 初始化失败，程序会自动改用 Edge 应用模式打开。

**Q：显示「官方启动器正在运行」？**
Paradox 官方启动器会独占 `launcher-v2.sqlite`。关掉它（托盘也退掉）再保存。

**Q：模组显示「待注册」？**
这些是创意工坊新订阅、但还没生成 `.mod` 描述文件的。到「创意工坊」页点「一键注册全部」。

**Q：改了排序但游戏里没变？**
看概览页的一致性检测。如果显示不一致，点「按当前播放集修复」。

**Q：会不会把我存档搞坏？**
不会。启动器只碰 `launcher-v2.sqlite` 和 `dlc_load.json`，不碰 `save games` 里的文件（除非你在存档页主动删除，那是移进回收站）。
