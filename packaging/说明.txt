人联启动器 v1.7
===================================

一个用于 Paradox 全家桶游戏的第三方启动器。
主适配《十字军之王 3》(Crusader Kings III)，顶部可切换到
群星、钢铁雄心 IV、维多利亚 3、欧陆风云 IV、欧陆风云 V、
十字军之王 II、帝国：罗马、城市：天际线、城市：天际线 II。
绿色免安装，解压即用，不写注册表。

完全开源，源码地址见文末「开源」一节。

功能
----
· 多游戏切换：顶部下拉一键切换，切换后自动刷新，各游戏配置独立保存
· 模组管理：双栏拖拽排序、搜索、按兼容性筛选、批量开关
· 模组操作：改显示名、复制工坊 ID、打开目录、手动纠正来源标签、删除（走回收站）
· 收藏夹：可建任意多个自定义收藏夹，一个模组能同时收进多个，点标签即筛选
· 拖入安装：把 .zip / .7z / .rar 拖到窗口任意位置，自动解压、识别 descriptor.mod
  并装进 mod 目录，同时生成 .mod 描述文件；支持一次拖多个包，重名自动编号，
  不用安装 7-Zip（7z / rar 走 Windows 自带 tar.exe）
· 冲突排查：一键扫描当前播放集里已启用的模组，报告四类问题 ——
  文件覆盖（标出谁覆盖谁、谁最终生效）、本地化键重复、依赖缺失、
  replace_path 整目录替换风险；按高/中/低分级，带逐模组扫描进度
· 打包分享：把任意模组打成 zip，别人拖回启动器就能装
· 播放集：新建 / 克隆 / 重命名 / 删除 / 导入导出（可自选保存位置）；
  导入时按 Steam ID 匹配本地模组，缺失的工坊模组自动订阅
· DLC 管理：读取游戏目录，向 Steam 校验授权，识别第三方解锁补丁，
  二维筛选（状态×官方七类），未拥有的锁灰；DLC 名称显示中文
· 成就：读取本机 Steam 成就记录，显示解锁进度、完成时间、全球完成率、稀有成就
· 存档管理：列出与清理存档（删除走回收站）
· 创意工坊：订阅清单 + 本地搜索、跳转工坊页、新订阅一键识别
· 游戏文件：自定义存档目录与模组目录，可一键恢复默认
· 版本切换：侧边栏独立页。版本配置管多套数据目录（名称 / 版本号 / 独立目录 /
  一键切换，顶栏出现版本下拉），Steam 切换管游戏本体版本，两者分工明确
· 百科：十字军之王 3 七类 932 条 / 群星十类 2436 条速查，
  全部离线读取游戏本体脚本与官方本地化。
  离线、可搜索、按类别筛选，详情含数值、克制关系、传统与实际效果；
  数据取自游戏本体，随版本自动更新
· 文件目录：多个快捷入口，一键打开各类游戏目录与数据文件
· 内存管理：查看物理内存与提交上限、一键优化、页文件信息
· 崩溃诊断：一键收集系统/日志/崩溃/mod 信息，生成诊断包
· 一致性检测：发现「播放集勾选」与「游戏实际加载」不一致
· 界面语言：中文 / English / Français / Deutsch / Svenska，
  在「启动器设置 → 界面语言」切换，即时生效并记住

注：DLC、成就、模组清单读取一次后会缓存到程序目录，
下次打开秒开；想重新核对时点页面右上角的「重新校验 / 刷新」。

【重要】被杀毒软件误报怎么办
----------------------------
本程序是 Python 打包成的单文件 exe，没有购买数字签名证书（一年几千块），
杀软的启发式引擎有一定概率把它误判成木马，常见名字：
  Trojan:Win32/Bearfoos.B!ml、Wacatac.B!ml、Zusy、AutoIt 之类
（名字末尾带 !ml 表示是「机器学习猜的」，不是真的特征匹配）

这类误报只因为你是一个「自己解压自己、释放文件到临时目录、再起子进程」的
无签名 exe —— 而这恰好是打包工具的通用行为，不是本程序干了什么坏事。

如果解压后 exe 直接不见了 / 双击被拦截：
  1. Windows 安全中心 → 病毒和威胁防护 → 保护历史记录
     → 找到对应记录 → 点「操作」→「还原」（如果还在隔离区）
  2. 加排除：病毒和威胁防护 → 管理设置 → 排除项 → 添加排除项 → 选「文件夹」
     → 选中解压出来的整个文件夹
  3. 360 / 火绒 / 电脑管家：在「信任区」或「白名单」里把解压目录加进去
  4. 加完后重新解压一次压缩包，exe 就能正常留在目录里了

不放心的话，可以直接翻源码（全程只用 Python 标准库，没有任何网络上传）：
  Gitee（主仓库） https://gitee.com/xiaoyi2233/renlian-launcher
  GitHub（镜像）  https://github.com/xiaoyi201610/renlian-launcher

关于排序
--------
每次保存会同时写入两处，保证排序真正生效：
  1. launcher-v2.sqlite  → playsets_mods.position（官方启动器界面顺序）
  2. dlc_load.json       → enabled_mods 数组（游戏启动真正读取的顺序）

加载规则：列表中位置越靠下，优先级越高，会覆盖上方模组的同名文件。

数据安全
--------
写盘前自动备份到程序目录下的 backups/，内容相同不重复存，
每种文件最多保留最近 12 份。
程序不主动修改存档文件；存档页的删除操作会移入 Windows 回收站。

DLC 中文名
----------
Paradox 在 Steam 商店里没给 DLC 设中文名（切简中拉回来还是英文），
游戏本体的中文包里也没有 DLC 名称条目，所以本程序内置了一份完整的
对照表，覆盖全部支持的游戏：主标题显示中文，英文原名放在下面小字。

这份对照表打包在程序里、完全离线，不需要额外装任何汉化补丁。

遇到新出的 DLC 还没中文名，或者想把某个译名改成自己喜欢的说法：

  1. 打开「DLC 管理」页，点右上角「自定义中文名」
  2. 会打开程序目录下的 dlc-names-cn.json（第一次自动生成，带示例）
  3. 照格式加一行：  "英文原名": "中文名",
  4. 保存，回启动器点「重新校验」即可生效

英文名大小写不限，前面的 Expansion - / Victoria 3: 之类的词可以省略，
直接复制 DLC 卡片上的英文小字最稳。这个文件优先级最高，会覆盖内置翻译。
文件格式是 JSON：每一项结尾要有英文逗号（最后一行不要），引号必须是英文双引号。

即使完全不管，也只会那一个新 DLC 显示英文，其他照常，不影响使用。

（给改源码的人：内置表在 backend/dlc_cn.py，加一行 "英文名": "中文名" 即可，
  改完记得把 server.py 里的 _DLC_CACHE_VER 加 1。）

隐私
----
程序不上传任何数据、没有统计和遥测。界面通过本地端口与后台通信，
仅监听 127.0.0.1，外部无法访问。

会联网的只有三处，且都可以不用：
  · DLC 授权校验 —— 多数情况是问本机 Steam 客户端，不经过互联网
  · DLC 详情弹窗 —— 从 Steam 商店拉介绍和截图（有本地缓存）
  · 成就的「全球 X%」—— 请求 Steam 公开统计接口，只发游戏 ID
这三处连不上时会自动降级，不影响其他功能。

技术
----
Python 3 + 标准库实现的本地服务，配合 WebView2 渲染界面。
无需安装依赖，也不需要单独装 Python。WebView2 是 Windows 10/11 自带组件。
